# SportsVerse_NSBM

A web-based sports management platform developed as a group project by students of the Faculty of Computing, NSBM Green University.

## Overview

SportsVerse helps manage sports activities at the university, including teams, players, events, and results, through a simple web interface backed by a database.

## Tech Stack

- **Frontend:** HTML, JavaScript
- **Backend:** PHP
- **Database:** MySQL

## Project Structure

| Folder / File | Description |
|---------------|-------------|
| `admin/` | Admin panel pages |
| `assets/` | Images, styles and other static files |
| `config/` | Configuration files (database connection, settings) |
| `database/` | SQL schema and sample data |
| `legacy/` | Earlier versions of the project files |
| `lib/` | Shared helper functions and libraries |
| `api.php` | API endpoint for the application |

## Getting Started

1. Clone the repository
   ```bash
   git@github.com:chamodwijayalath/NSBM_SortsVerse.git
   ```
2. Install a local server such as XAMPP or WAMP.
3. Copy the project folder into the `htdocs` directory.
4. Import the SQL file from the `database/` folder into MySQL (phpMyAdmin).
5. Update the database credentials in the `config/` folder.
6. Open `https://nsbmsportsverse.nfy.fyi` in your browser.
